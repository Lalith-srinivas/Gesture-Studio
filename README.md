# ✨ About

Gesture Studio is an interactive browser-based gaming platform where players control games using **real-time hand gestures**.

Instead of traditional keyboard or controller input, users can interact naturally using their webcam. Every game is designed with gesture support in mind while still providing keyboard and mouse controls for accessibility.

This project explores the intersection of:

- 🤖 Computer Vision
- 🎮 Browser Game Development
- 🖐️ Gesture Recognition
- ⚡ Modern Frontend Engineering
- 🎨 Interactive UI Design

# 🖐️ Gesture Controls

| Gesture | Action |
|----------|--------|
| ☝️ Index Finger | Select / Confirm |
| ✌️ Two Fingers | Secondary Action |
| 🤏 Pinch | Grab / Shoot / Launch |
| ✋ Open Palm | Pause / Release |
| ✊ Fist | Reset / Cancel |
| 👈 Move Left | Move Left |
| 👉 Move Right | Move Right |

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/your-username/gesture-studio.git
```

Move into the project

```bash
cd gesture-studio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
